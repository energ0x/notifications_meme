## 📖 Про проєкт (Overview)

**Notifications Meme** — це зручний та функціональний iOS-застосунок, розроблений на **SwiftUI**, призначений для гнучкого створення та планування кастомних локальних сповіщень. Додаток дозволяє з високою точністю симулювати пуш-повідомлення від будь-яких сервісів (Telegram, Instagram, Tinder, Monobank, Дія тощо) для створення мемів, пранків, зйомки контенту для соцмереж (TikTok, Reels, Shorts) або тестування сценаріїв взаємодії зі сповіщеннями на iOS.

Проєкт демонструє роботу з нативними фреймворками iOS, реактивне керування дозволами в реальному часі, планування фонових подій та чисту архітектуру.

## ✨ Ключові можливості (Features)

- ✍️ **Повна кастомізація контенту:**
  - Налаштування заголовка / назви сервісу чи автора (**Title**).
  - Додатковий рядок контексту (**Subtitle**).
  - Основний текст повідомлення (**Body**).
- ⏱️ **Гнучке планування часу (Scheduling):**
  - Вибір точної дати та часу надходження першого сповіщення через інтерактивний `DatePicker`.
  - Автоматична корекція: якщо обраний час уже минув, сповіщення спрацює миттєво (+1 сек).
- 🔁 **Серія сповіщень (Burst & Intervals):**
  - Налаштування кількості сповіщень у серії (від 1 до 100).
  - Налаштування інтервалу між сповіщеннями (від 1 секунди до 1 години).
- 📲 **Підтримка Foreground-сповіщень:**
  - Реалізація `UNUserNotificationCenterDelegate`, що забезпечує показ банерів та звукових сигналів навіть під час активної роботи в додатку.
- 🔒 **Реактивна робота з системними дозволами (Permissions):**
  - Автоматична перевірка та динамічний запит прав на показ сповіщень (`.alert`, `.badge`, `.sound`).
  - Реактивна зміна інтерфейсу залежно від стану авторизації користувача.

## 🏗️ Архітектура та структура проєкту

Проєкт спроєктований за принципами чистої архітектури та декларативного підходу з чітким розділенням інтерфейсу та сервісного шару:

```text
notifications_meme/
├── notifications_memeApp.swift     # Точка входу в застосунок (@main App Lifecycle)
├── ContentView.swift               # Головний інтерфейс користувача (SwiftUI View & Form)
├── NotificationManager.swift       # Сервіс планування сповіщень та дозволів (UserNotifications + Combine)
├── Assets.xcassets/                # Графічні ресурси, кольори та іконка застосунку
│   ├── AccentColor.colorset
│   └── AppIcon.appiconset          # Системний набір іконок для iOS (1024x1024)
└── notifications_meme.xcodeproj    # Конфігурація проєкту Xcode
```

### Основні компоненти:

1. **`NotificationManager.swift`**:
   - Реалізує `ObservableObject` та виступає делегатом `UNUserNotificationCenterDelegate`.
   - `requestAuthorization()`: асинхронно запитує дозвіл користувача на відправку сповіщень.
   - `checkAuthorizationStatus()`: перевіряє статус дозволів у системних налаштуваннях iOS.
   - `scheduleNotifications(...)`: формує чергу `UNNotificationRequest` з унікальними `UUID` та тригерами `UNCalendarNotificationTrigger`.
   - `userNotificationCenter(_:willPresent:...)`: налаштовує представлення сповіщень при активному додатку (`[.banner, .sound]`).

2. **`ContentView.swift`**:
   - Декларативна форма (`Form`) з двостороннім зв'язуванням (`@State`, `@StateObject`).
   - Динамічна зміна кольорів та дій кнопок відповідно до прав доступу.
   - Візуальне підтвердження успішного планування через системний `Alert`.

## 🎨 Як змінити іконку програми в сповіщенні (Важливо!)

> [!IMPORTANT]
> **Особливості та обмеження безпеки iOS (iOS Sandboxing):**  
> В операційній системі iOS іконка, що відображається біля push-сповіщення, **завжди береться з системної іконки самого додатка (`AppIcon` у бандлі застосунку)**. З міркувань безпеки Apple не дозволяє сторонньому додатку "на льоту" змінювати системну іконку сповіщення на логотипи інших встановлених програм.
> 
> **Щоб змінити іконку програми у сповіщенні (наприклад, встановити логотип Telegram, Instagram, Monobank тощо), необхідно власноруч перекомпілювати застосунок зі своєю іконкою в Xcode.**

### Покрокова інструкція заміни іконки:

1. **Підготуйте зображення:**
   - Знайдіть або підготуйте квадратне зображення потрібного сервісу розміром **1024x1024 пікселів** у форматі PNG (без прозорого альфа-каналу).
2. **Відкрийте проєкт у Xcode:**
   - Відкрийте файл `notifications_meme.xcodeproj`.
3. **Замініть іконку в Assets:**
   - У навігаторі проєкту відкрийте папку `notifications_meme` ➔ `Assets` (або `Assets.xcassets`).
   - Виберіть пункт **`AppIcon`**.
   - Перетягніть підготовлений файл у слот **1024x1024 (iOS Universal)**, замінивши поточний `icon-2.png`.
4. **Перекомпілюйте та встановіть застосунок:**
   - Підключіть свій iPhone або виберіть Симулятор.
   - Натисніть **`Cmd + R`** (або кнопку **Run ▶** у верхній панелі Xcode).
5. Після перевстановлення всі нові сповіщення приходитимуть з обраною вами іконкою!

## 🚀 Встановлення та запуск (Getting Started)

### Системні вимоги:
- macOS з встановленим **Xcode 15.0+**
- Пристрій або симулятор з **iOS 16.0+**

### Кроки для запуску:

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/energ0x/notifications_meme.git
   cd notifications_meme
   ```

2. **Відкрийте проєкт в Xcode:**
   ```bash
   open notifications_meme.xcodeproj
   ```

3. **Налаштуйте підпис (Signing & Capabilities) для реального пристрою:**
   - У лівій панелі оберіть проєкт `notifications_meme`.
   - Перейдіть у вкладку **Signing & Capabilities**.
   - Оберіть вашу команду розробника (**Team**) або безкоштовний Apple ID акаунт.
   - При необхідності змініть **Bundle Identifier** на свій власний.

4. **Запустіть білд:**
   - Оберіть цільовий пристрій чи симулятор у списку схем.
   - Натисніть **Run** (`⌘R`).
   - Надайте дозвіл на сповіщення при першому запуску програми.

## 📱 Як користуватися застосунком

1. **Налаштуйте текст:**
   - **Заголовок:** Вкажіть ім'я відправника або назву сервісу (наприклад, `Telegram`, `Instagram`, `Monobank`).
   - **Підзаголовок:** (Опціонально) додатковий контекст (наприклад, `Нове повідомлення`).
   - **Текст повідомлення:** Основне повідомлення.
2. **Встановіть параметри відправки:**
   - Виберіть дату та час першого сповіщення.
   - Вкажіть кількість повторень (від 1 до 100).
   - Вкажіть інтервал у секундах між повідомленнями.
3. **Заплануйте сповіщення:**
   - Натисніть кнопку **"Запланувати сповіщення"**.
   - Заблокуйте телефон або згорніть додаток та насолоджуйтеся результатом!

## 💼 Цінність проєкту для портфоліо

- **Робота з системними API iOS:** Практичний досвід використання `UserNotifications`, обробка фонових тригерів, календарних подій та життєвого циклу повідомлень.
- **Чистий декларативний UI:** Використання сучасного SwiftUI без сторонніх бібліотек, якісна структуризація стану та форм введення.
- **Увага до деталей (Edge Cases):** Передбачено випадки, коли час у минулому, коректна робота у foreground-режимі, плавна реактивність на зміну дозволів користувачем.
